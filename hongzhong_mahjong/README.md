# 红中麻将（Python 简化版，人机对战）

这是一个基于 `tkinter` 的简化红中麻将小游戏，使用本仓库中的麻将 PNG 图片（`Export/Regular/*.png`）作为牌面资源。

## 规则（简化）
- 2 人对战：你 vs 电脑。
- 牌池：万/筒/索 1-9 各 4 张 + 红中（Chun）4 张。
- 开局各 13 张。
- 每回合：摸 1 张 -> 打 1 张。
- 胡牌：`4 组面子 + 1 对将`。
- 红中作为万能牌（癞子）参与胡牌计算。

## 运行方法
在仓库根目录执行：

```bash
python3 hongzhong_mahjong/main.py
```

## 文件说明
- `main.py`：程序入口。
- `game/tiles.py`：牌定义与图片路径映射。
- `game/rules.py`：胡牌判定逻辑（含红中万能牌）。
- `game/ai.py`：电脑打牌策略（启发式）。
- `game/ui.py`：Tk 图形界面与对局流程。
